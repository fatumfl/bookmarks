# Требования к системе Bookmarks

```
> [N] - New - Новое нереализованное требование
> [A] - Active - Действующее реализованное требование
> [U] - Update - Уточненное требование
> [C] - Cancelled - Отмененное требование
> [R] - Reviewing - Требуют подтверждения пользователя
```

## GEN — Общие условия
* [A] ADR001-GEN: Название системы — Bookmarks.
* [A] ADR002-GEN: Система предназначена для однопользовательского использования и распространяется как готовое к публикации на статических хостингах (например, GitHub Pages) веб-приложение.
* [A] ADR003-GEN: При первом запуске системы или после сброса состояния по умолчанию создаётся ровно одна папка Home с единственной закладкой https://google.com (теги `#search #web`, иконка `<favicon>`).
* [A] ADR004-GEN: При первом запуске (или после очистки состояния) единожды отображается приветственное окно с описанием назначения программы, принципов работы, предупреждением о возможной потере данных в localStorage, необходимости ручного экспорта/импорта JSON, информацией об отсутствии гарантий (AS IS) и ссылкой на лицензию (@licence, текст лицензии — заглушка Lorem Ipsum).
* [R] ADR041-GEN: При наличии неэкспортированных изменений (`hasUnsavedExport`) и попытке закрытия/перезагрузки вкладки отображать стандартное предупреждение браузера (`beforeunload`), чтобы снизить риск случайной потери данных.

## ARCH — Архитектура
* [A] ADR005-ARCH: Приложение реализуется как Single Page Application (SPA) полностью в одном файле index.html (HTML, CSS, JS).
* [A] ADR006-ARCH: Запрещены внешние экспорты и обращения к сторонним источникам (CDN для фреймворков, иконок, шрифтов); приложение должно работать автономно на чистом HTML/CSS/JS без внешних зависимостей и без подключения к интернету. Загрузка иконок сайтов/фавиконок разрешена в рамках политики безопасности контента (`img-src https: http: data:`).
* [A] ADR007-ARCH: В тело index.html встраивается предопределённый список из 100 SVG-иконок для выбора иконок папок.
* [U] ADR008-ARCH: В index.html задаётся строгая Content Security Policy (`default-src 'none'; img-src https: http: data:; style-src 'unsafe-inline'; script-src 'unsafe-inline'; base-uri 'none'; form-action 'none'; frame-src 'none'; object-src 'none'`) и санитизация URL (`http:`, `https:`, `ftp:`, `mailto:`), запрещающая опасные схемы (`javascript:`, `data:` для ссылок, `vbscript:`, `file:`, `blob:`).
* [R] ADR042-ARCH: Вынести встроенный список из 100 SVG-иконок и переводы/константы в структурированный блок конфигурации внутри `<script>` с явной проверкой целостности при инициализации и упростить замену `&nbsp;` на DOM-создание текстового узла `\u00a0`.

## STOR — Хранилище и работа с данными
* [U] ADR009-STOR: Данные пользователя разделены на хранилище папок и закладок (`bookmarks_data_v3`, версия схемы 3, с флагом неэкспортированных изменений `dirty`) и хранилище настроек интерфейса (`bookmarks_prefs_v3`) в `localStorage` с fallback-хранилищем в памяти, запросом `navigator.storage.persist()`, резервным копированием повреждённых данных (`bookmarks_corrupt_backup_*`) и миграцией из `bookmarks_single_user_v2`.
* [A] ADR010-STOR: Поддерживается экспорт данных в JSON и импорт данных из JSON (включая опциональное применение настроек интерфейса из файла резервной копии).
* [A] ADR011-STOR: При импорте из JSON система запрашивает у пользователя режим применения данных: добавить/объединить (`Add / Merge`, добавление новых папок и пропуск закладок с уже существующим URL в папке с тем же именем) или полностью перезаписать текущие (`Overwrite All`).
* [A] ADR012-STOR: Если с момента последнего экспорта в данных были изменения, кнопка импорта/экспорта окрашивается в красный цвет (`unsaved-dirty`), пока пользователь не выполнит экспорт в JSON (предупреждение о риске потери данных при очистке браузера).
* [U] ADR013-STOR: Поддерживается отмена и повтор действий над папками и закладками (стек снимков до 50 шагов) через кнопку отмены в панели инструментов, горячие клавиши (`Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z` / `Ctrl/Cmd+Y`), кнопку действия в уведомлении (toast) и команду `@undo`; иконка отмены меняет состояние между тусклым и активным в зависимости от наличия шагов для отмены.
* [R] ADR043-STOR: Добавить проверку на дубликаты и нормализацию URL при слиянии (`Add / Merge`) импортируемых закладок (например, сравнение с учётом схемы/хоста/слэша), а также отображать размер и дату последнего экспорта в модальном окне резервного копирования.

## UI — Пользовательский интерфейс
* [A] ADR014-UI: Оформление следует современным стандартам WEB/Android интерфейсов и Material Design 3; предусмотрен градиентный фон, адаптированный под светлую и тёмную темы.
* [A] ADR015-UI: На левой панели папок рядом с названием Bookmarks отображается иконка скрепки.
* [A] ADR016-UI: Панель папок поддерживает два состояния, переключаемых кнопкой вверху панели: свёрнутое (compacted, только иконки папок) и развёрнутое (maximized, иконка, название и счётчик закладок рядом).
* [A] ADR017-UI: Внизу панели папок размещается кнопка создания новой папки с иконкой «папка со знаком плюс в правом нижнем углу», а над ней — кнопка блокировки/разблокировки сортировки папок с иконкой замка, отключающая сортировку папок перетаскиванием.
* [A] ADR018-UI: В развёрнутом виде панели папок (а также на тач-устройствах) при наведении/фокусе на папку рядом с кнопкой удаления появляется кнопка редактирования папки.
* [A] ADR019-UI: Всплывающее окно создания/редактирования папки открывается ближе к кнопке, вызвавшей его (для создания внизу — ближе к нижней кнопке; для редактирования — ближе к кнопке редактирования папки с учётом границ экрана), и позволяет выбрать иконку из 100 встроенных SVG и задать название.
* [U] ADR020-UI: Карточка закладки имеет максимальный размер 280x110 px и ширину по умолчанию 280 px (сжимается по ширине только при нехватке места в колонке/экране).
* [A] ADR021-UI: Оформление карточек закладок адаптировано под светлую и тёмную темы: крупная иконка сайта (с fallback на `<favicon>` и буквенный аватар при отсутствии/ошибке загрузки иконки), теги выровнены по левому краю блока названия, лишние не помещающиеся по ширине или в два ряда теги скрываются с индикатором `+N`, а кнопки редактирования и удаления выводятся над карточкой.
* [A] ADR022-UI: В режиме сетки отсутствует заголовок таблицы, карточки имеют переменный оттенок фона, а внизу блока закладок отсутствуют стрелки прокрутки и нижняя горизонтальная линия.
* [A] ADR023-UI: Внизу экрана при наличии нескольких страниц карусели отображается индикатор страниц в виде кругляшков с выделением активной страницы.
* [A] ADR024-UI: В режиме списка отображается таблица с колонками (иконка слева, название сайта, URL, действия редактирования/удаления) и следующей привязанной строкой со списком тегов; полоса прокрутки не налезает на скруглённые границы списка.
* [A] ADR025-UI: Над закладками размещается поисковая строка (с повышенной контрастностью и заметностью в светлой теме) и строка подсказок с примерами фильтров: `#tag`, `.domain`, `/folder`, `text`.
* [A] ADR026-UI: Плавающая панель настроек располагается в правом нижнем углу вертикально (сверху вниз), а на мобильных устройствах (`<= 720px`) — внизу экрана горизонтально (слева направо), без наложения на свёрнутую панель папок и кнопку добавления папки.
* [A] ADR027-UI: Плавающая панель настроек содержит элементы управления: отмена действия, выбор размеров сетки в виде таблицы, переключение вида сетка/список, переключение тёмной и светлой темы, переключение обычного и моноширинного шрифта, переключение языка интерфейса русский/английский (на узких экранах редкие переключатели скрываются в меню «Ещё»), импорт/экспорт JSON и добавление закладки (иконка «закладка со значком плюс в правом нижнем углу»).
* [A] ADR028-UI: Всплывающий диалог создания/редактирования закладки содержит поля выбора папки, названия, URL сайта/ресурса, URL иконки (по умолчанию `<favicon>`), списка тегов в формате `#tag1 #tag2 #tag3`; диалог оформлен единообразно в светлой и тёмной темах.
* [R] ADR044-UI: Добавить индикатор активных фильтров/количества найденных результатов в виде сбрасываемых чипов рядом со строкой поиска, чтобы пользователь мог быстро удалять отдельные фильтры (`#tag`, `.domain`, `/folder`) одним кликом.

## UX — Пользовательский опыт и взаимодействие
* [A] ADR029-UX: Закладки и результаты поиска всегда открываются в новой вкладке браузера (`target="_blank" rel="noopener noreferrer"`).
* [A] ADR030-UX: Поддерживается изменение порядка папок перетаскиванием (drag-and-drop на десктопе и долгим нажатием на тач-устройствах), если сортировка не заблокирована кнопкой блокировки.
* [A] ADR031-UX: Поддерживается изменение положения закладок на странице и перенос закладок между папками перетаскиванием (drag-and-drop).
* [A] ADR032-UX: Нажатие на тег в режиме сетки или списка подставляет этот тег в строку поиска.
* [A] ADR033-UX: Перелистывание страниц карусели закладок поддерживается колесиком мыши, жестом указателя/свайпом и клавишами влево/вправо на клавиатуре.
* [U] ADR034-UX: При вводе `@` в поисковой строке отображается выпадающий список доступных `@`-команд с кратким описанием, а при вводе `#`, `/` или `.` в последнем токене — подсказки по тегам, папкам и доменам с поддержкой навигации стрелками, `Tab` и `Enter` (для деструктивной команды `@clear` по неполному вводу выполняется только автодополнение).
* [U] ADR035-UX: Поддерживаются клавиатурные сокращения: `Ctrl/Cmd+K` или `/` — фокус в поиске, `Esc` — закрытие выпадающих списков, поповеров и модальных окон (с ловушкой фокуса `Tab` внутри модальных окон), `Enter` в поиске — переход к первому совпадению или поиск в Google при обычном текстовом запросе без совпадений.
* [R] ADR045-UX: Добавить поддержку перетаскивания закладок между папками и на тач-устройствах (в дополнение к перестановке внутри папки и свайпам страниц карусели).

## FR — Функциональные требования
* [A] ADR036-FR: Каждая папка хранит собственный набор закладок; закладка содержит название, URL ресурса, URL иконки (с fallback на `<origin>/favicon.ico` и затем на буквенный аватар) и список тегов в формате `#tag1 #tag2 #tag3` (до 20 уникальных тегов в нижнем регистре).
* [U] ADR037-FR: Поиск по закладкам выполняется интерактивно по всем папкам с поддержкой обычного текста (по названию и URL) и комбинаций фильтров в любом порядке: `/foldername` (папка, логическое ИЛИ при нескольких), `#tagname` (тег, логическое И), `.domain` (домен по границам доменных меток, логическое ИЛИ при нескольких), обычный текст (логическое И), включая строки в кавычках для значений с пробелами.
* [A] ADR038-FR: Результаты поиска выводятся в формате `Folder Icon + Folder Name -> Bookmarks favicon -> Bookmarks Name -> [tag1; tag2; tag3]`.
* [U] ADR039-FR: Строка поиска поддерживает выполнение команд: `@export` (экспорт в JSON), `@import` (импорт из JSON), `@clear` (очистка хранилища и сброс системы с подтверждением), `@undo` (отмена последнего действия), `@licence` / `@license` (открытие лицензии), `@welcome` (открытие приветственного окна).
* [R] ADR046-FR: Добавить возможность пакетного удаления или переноса нескольких выбранных закладок, а также быстрое копирование URL закладки по дополнительному действию в карточке/строке списка.

## NFR — Нефункциональные требования
* [A] ADR040-NFR: Интерфейс адаптирован под экраны различных размеров — от широкоформатных ПК до узких мобильных экранов; базовый размер шрифта составляет 16 px для обычного шрифта и 18.5 px для моноширинного (`[data-font="mono"]`).
* [U] ADR041-NFR: Размер сетки настраивается таблицей (до 8x8) и учитывает доступные размеры области закладок: минимальный размер составляет 3x3 на большом экране и 1x3 на мобильном (с ограничением реально помещающимися столбцами и строками, а также блокировкой недоступных ячеек в пикере); изменение размера сетки меняет компоновку, а не стандартный размер карточки (280x110 px).
* [A] ADR042-NFR: Закладки, не вмещающиеся по ширине, переносятся на следующую строку, а не вмещающиеся по высоте (за пределами `cols * rows`) — на следующую страницу карусели.
* [R] ADR047-NFR: Добавить базовый набор автоматизированных модульных и DOM-тестов (например, для `sanitizeUrl`, `parseTags`, `tokenizeQuery`, `runGlobalSearch`, миграций и `undo/redo`) в репозитории для защиты от регрессий при правках `index.html`.
