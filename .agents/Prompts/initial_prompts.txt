# Initial Prompt
Write me a full copy of MONKNOW New Tab for single user usage as a single page application - all in one index.html (html, css, js) - no external exports or sourcing (like CDNs for frameworks, icons, fonts). Just bare and clean HTML/CSS/JS, without any dependencies, to publish on static site hostings like GitHub Pages.
 Functionality and layout:
1. Folders on the compacted left panel showing only icons from predefined (included in index.html) list of svg icons (100 included icons). Each folder hosts its own list of bookmarks. Left panel could be compacted (showing only icons for created folders) or maximized (showing name of the folder beside icon) using toggle on the top of left panel. On the bottom - folder with plus sign for adding new folders (pop up window shows up near plus sign asking to select predefined icon and enter folders name).
2. In the middle of page - users bookmarks for selected folder. Закладка выглядит следующим образом: слева - иконка сайта, подгружается как favicon заданного пользователем URL сайта, либо пользователь напрямую задает URL ссылку на иконку при создании закладки (c fallback на favicon); справа, вертикальное выравнивание по центру иконки - название сайта, под названием - список тегов в формате #tag1 #tag2 #tag3 - заданных пользователем для этой закладки. Закладки всегда открываются в новой вкладке браузера.
3. Over bookmarks - search field for interactive bookmarks search among all folders. Bookmarks could be searched by name (entering plane text), and filtered by domains (in the format .domain for example: .ru, .com, .local, .google), tags (#tagname) or folders (/foldername). Examples: `@searchtag` - all bookmarks with specified tag, `@searchtag part_of_name` - all bookmarks with specific text in name tagged by searchtag. Search results format: Folder Icon -> Bookmarks favicon -> Bookmarks Name -> [tag1; tag2; tag3] (list of tags).
4. On the right bottom side - floating configuration panel, со следующими иконками, сверху-вниз (на мобильных устройствах внизу экрана слева-направо): 1. изменение размеров сетки закладок (количество закладок по вертикали и горизонтали) - задается в виде таблицы (как элемент Insert -> Table в Word), помимо этого количество закладок по ширине еще зависит и от ширины экрана (все элементы должны быть адаптивными - сайт используется как на широкоформатных ПК, так и на мобильных устройствах с узкими экранами) - невмещающиеся закладки переносятся на новую строку к следующим, если не вмещаются по высоте экрана - переносятся на новую страницу "карусели" - при этом внизу экрана появляется индикатор страницы карусели в виде кругляшков, активный подсвечивается / выделяется; 2. переключение вида с сетки (иконки слева от текста) на список, список отображется в виде таблицы с колонками: слева иконка, затем название сайта, затем URL, следующей привязаной строкой - список тегов. 3. переключение между темной и светлой темой; 4. переключение между обычным и моноширинным шрифтом; 5. переключение языка интерфейса между русским и английским; 6. экспорт и импорт закладок в/из JSON (при импорте система должна спросить - добавить ли новые Folders или полностью перезаписать текущие); 7.  добавление новой закладки (при нажатии открывается новый всплывающий диалог).
5. Всплывающий диалог создания новой закладки содержит следующие поля: Название закладки, URL-сайта / ресурса, URL для иконки (по умолчанию значение <favicon>), список тегов в формате #tag1 #tag2 #tag3.

Вся информация о сессии пользователя (настройках, закладках) хранится в localStorage браузера. Если были изменения, то кнопка импорт/экспорт окрашивается в красный, пока пользователь не экспортирует данные в JSON - чтобы пользователь знал, что может потерять данные при очистке браузера.

UX/UI должен соотвествовать современным стандартам WEB/Android интерфейсов, следовать Material Design Guidelines, быть адаптивным.

Выведи только один блок кода ```html ``` со всем кодом сервиса сразу. Не выводи никакой дополнительной информации - размышлений, приветствий, сопутствующего текста и т.д. Это должно быть полнофункциональное приложение соответствующее всем обозначенным требованиям.
